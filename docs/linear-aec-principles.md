## 1. 问题定义与系统模型

### 1.1 物理场景

免提/扬声器通话中，麦克风既拾取近端人声，也拾取扬声器播放出去的远端信号。后者即**声学回声**。

```
远端信号 x[n] ──► 扬声器 ──► 声学空间 h ──► 麦克风 ──► y[n]
                                (+ 近端人声 v[n], + 环境噪声)
```

### 1.2 数学模型

麦克风信号可写为：

```
y[n] = Σ_{k=0}^{L-1} h[k] · x[n − k − d]  +  v[n]
       └────────── 回声 e_echo[n] ──────┘     └─ 近端 + 噪声
```

| 符号 | 含义 |
|---|---|
| `x[n]` | 远端参考信号（扬声器输入） |
| `h[k]` | 扬声器→麦克风的**声学冲激响应**，长度 `L` |
| `d` | **纯时延**（设备缓冲 + 声传播），单位样本 |
| `v[n]` | 近端语音 + 环境噪声（与 `x` 不相关） |
| `y[n]` | 麦克风观测 |

关键观察：回声是 `x` 经过一个**线性、时不变（短时内）、有延迟**的系统后的输出。因此线性 AEC 的可解性建立在两个假设上：

- **A1（线性）**：扬声器、功放、房间传播、麦克风在正常音量下可用线性系统近似（小信号、无削波）。非线性失真归"残余回声抑制"处理。
- **A2（不相关）**：近端语音 `v[n]` 与远端信号 `x[n]` 不相关。

### 1.3 目标

AEC 的输出应当是**近端信号加噪声**，即把回声成分减掉：

```
e[n] = y[n] − ê_echo[n]  ≈  v[n]
```

其中 `ê_echo[n] = Σ_k ĥ[k]·x[n−k]` 是用估计的冲激响应 `ĥ` 卷积 `x` 得到。

**注意**：`e[n]` 同时是"被减后的输出"和"自适应滤波器的误差信号"——这个双重身份是 AEC 与普通自适应滤波完全一致的地方（用误差反馈驱动 `ĥ` 逼近 `h`）。

## 2. 线性 AEC 的本质：系统辨识

### 2.1 等价表述

线性 AEC = **自适应系统辨识（Adaptive System Identification）**：

> 有一个未知的线性系统 `h`（回声路径），可观测它的输入 `x` 和"输入经系统 + 干扰"的输出 `y`，要求在线估计 `ĥ(t)` 使其逼近 `h`。

由此可以直接借用自适应滤波的整套理论。

### 2.2 为什么必须"自适应"

`h` 不是常数，它随以下因素变化：

| 因素 | 变化时间尺度 |
|---|---|
| 房间/摆放/用户移动 | 秒～分钟 |
| 温度、气流 | 分钟 |
| 扬声器音量变化（等价于 `h` 整体缩放） | 瞬时 |
| 设备/驱动缓冲深度变化（改变 `d`） | 瞬时 |
| 采样时钟漂移（缓慢改变 `d`） | 分钟～小时 |

因此不能离线标定，必须**在线、逐块、自我纠正**。

### 2.3 误差信号的两个用途

```
e[n] = y[n] − ĥ ⊛ x[n]
```

- 作为**输出**：这就是"回声消除后"的信号，送给后续处理。
- 作为**代价**：`J = E{e[n]²}` 是自适应算法要最小化的目标。

在理想条件下（`v` 与 `x` 不相关、`ĥ` 可完全表示 `h`），最小化 `E{e²}` 的解就是 `ĥ = h`，此时 `e[n] = v[n]`。这说明**"消除回声"和"辨识系统"是同一件事的两面**。

## 3. 最优解与自适应算法

### 3.1 最优（维纳）解

设 `ĥ` 为长度 `L` 的 FIR，代价 `J(ĥ) = E{(y[n] − ĥᵀx_n)²}`，其中 `x_n = [x[n], x[n−1], …, x[n−L+1]]ᵀ`。

令 `∇J = 0` 得**维纳-霍夫方程**：

```
R_xx · ĥ_opt = r_yx
```

其中 `R_xx = E{x_n x_nᵀ}`（自相关矩阵），`r_yx = E{x_n y[n]}`（互相关向量）。

若 `v` 与 `x` 不相关，则 `r_yx = R_xx · h`，因此 `ĥ_opt = h`。**这是 AEC 可辨识性的理论根据。**

### 3.2 梯度下降与 LMS

实际无法求 `R_xx` 的逆（且时变），故用**随机梯度下降**，用瞬时值代替期望：

```
ĥ[n+1] = ĥ[n] + μ · e[n] · x_n        （LMS）
```

- `μ` 为步长（`0 < μ < 2/λ_max`，`λ_max` 为 `R_xx` 最大特征值）；
- 收敛速度由 `R_xx` 的**特征值扩散度**决定；语音/音乐的相关矩阵条件数很差（尤其窄带信号），这是 LMS 收敛慢的根本原因。

### 3.3 NLMS：对激励能量归一化

LMS 的步长对输入幅度敏感（`x` 放大 10 倍，等效步长放大 100 倍 → 发散）。归一化 LMS：

```
ĥ[n+1] = ĥ[n] + μ · e[n] · x_n / (‖x_n‖² + δ)
```

- `‖x_n‖²` 为输入向量的瞬时能量；
- `δ` 是**正则化小量**，防止除零 / 弱激励下增益爆炸。

这是 AEC 中最基本的更新式。稳态下等效步长为 `μ` 与能量无关。

### 3.4 收敛与失调的权衡

NLMS 的两个关键量：

- **收敛速度**：正比于 `μ`。
- **失调（misadjustment）**：稳态时 `ĥ` 的残余误差能量 `≈ μ/2 · E{e²_min}`，正比于 `μ`。

于是有经典矛盾：**大步长收敛快但稳态底噪高；小步长稳态好但跟不上变化**。

解决方案是**变步长**：前期大步长快速收敛，后期小步长精修。变步长通常由以下信号驱动：

1. **误差能量与参考信号能量的比值** —— 比值为 1 表示完全没消掉，比值为 0 表示完美；
2. **双讲检测** —— 检测到近端说话时冻结或减小步长；
3. **滤波器已收敛状态** —— 由频率响应/ERL 估计判断。

### 3.5 泄漏（Leakage）

纯 NLMS 有两个隐患：

- **激励不足时**：`‖x‖²` 很小，正则项 `δ` 主导，更新方向近似随机游走 → 系数漂移（diverge）。
- **有限精度下**：语音激励是宽带但非持续的，长期无激励的频段系数会慢慢"漂"。

加入**泄漏项**，把系数向 0 拉：

```
ĥ[n+1] = (1 − γ)·ĥ[n] + μ·e[n]·x_n/(‖x_n‖²+δ),     0 < γ ≪ 1
```

等价于在代价函数里加正则 `J = E{e²} + γ‖ĥ‖²`，把无激励频段的系数强行压回 0。这是**有偏估计**，但换来了稳定性。

### 3.6 仿射投影（AP）与更快的收敛

NLMS 只用当前一个样本的约束。若用最近 `P` 个样本的约束同时满足（`P` 阶仿射投影），收敛速度可提升数倍，代价是求一个 `P×P` 线性系统。这是语音 AEC 常用折中（`P = 2~4`）。

## 4. 长冲激响应的处理：分块频域自适应滤波

### 4.1 为什么时域 FIR 不够用

声学回声的"尾长"（混响时间）：

| 房间 | 典型混响 T60 | 对应冲激响应长度 @16 kHz |
|---|---|---|
| 小会议室 | 0.2 s | 3200 抽头 |
| 办公室 | 0.4 s | 6400 抽头 |
| 客厅 | 0.6 s | 9600 抽头 |

若再加上未补偿的延迟，长度可达上万。时域 FIR 的代价：

- 每样本需 `L` 次乘加做**滤波**、`L` 次做**更新** → `O(L)` 每样本，`L = 10⁴` 时单核即不可行；
- LMS 收敛时间正比于 `L/μ`，`L` 大则收敛慢到不可接受。

### 4.2 频域卷积的两条路

用 FFT 把卷积变成乘法，但需要处理"线性卷积 vs 循环卷积"的差异。两种经典方法：

**重叠保留法（Overlap-Save, OLS）**
- 取长度为 `2N` 的 FFT，其中后 `N` 点为当前块，前 `N` 点保留上一块；
- 循环卷积的结果中，**后 `N` 点恰好等于线性卷积的后 `N` 点**（有效的部分）；
- 每块只需一次 FFT（`x`）+ 一次 IFFT（输出）。
- 滤波器抽头数 `L = N`。

**重叠相加法（Overlap-Add, OLA）**
- 每块补零到 `2N`，卷完的结果前后段相加；
- 需要额外一次 FFT 处理滤波器（若滤波器固定）或两次 IFFT。

**AEC 里用 OLS 更自然**，因为它与"逐块处理、逐块输出"的实时结构吻合。

### 4.3 分块（分区）频域自适应滤波 — PBFDAF

当 `L` 远大于块长 `N` 时，把 `h` 切成 `P = ⌈L/N⌉` 段（partition），每段用一个长度为 `2N` 的频域滤波器 `H_p` 表示：

```
ĥ  =  [ h_0 | h_1 | … | h_{P−1} ]       每段 N 抽头
H_p = FFT( [h_p 的 N 点, 补 N 个零] )     长度 2N 的复数向量
```

**滤波（卷积）**：

```
S[k] = Σ_{p=0}^{P−1} X_{n−p}[k] · H_p[k]
```

其中 `X_{n−p}[k]` 是延迟 `p` 块的参考信号 FFT。这是因为 `h_p` 作用于 `x[n − pN … n − (p+1)N + 1]`，即第 `p` 段过去的输入。

**输出**：`S` 做 IFFT，取有效的那 `N` 点，从 `y` 中减去得到 `e`。

**代价**：每块 `P` 次复数乘（频域），加上一次 IFFT + 一次 FFT，即 `O(P·N + N log N)` 每块 = `O(L + N log N)` 每块，而时域是 `O(L·N)` 每块。**当 `N` 较大时降一个量级。**

### 4.4 频域 NLMS 更新

分块后，更新也在频域做。频域 NLMS 的标准形式：

```
H_p[k] ← H_p[k] + μ · (E[k] · conj(X_{n−p}[k]))  /  (Σ_p |X_{n−p}[k]|² + δ)
```

要点：

- **分母是各 partition 输入功率之和**（相当于对整体 `‖x‖²` 的频域近似），故称"partitioned block frequency domain NLMS"。
- `E[k]` 是误差块的 FFT——**注意这里存在一个微妙的近似**：严格推导中应该用"梯度约束"后的误差，工程上常直接用当前块误差的 FFT，引入的偏差由时域约束（见下）来纠正。
- 更新式本质仍是 `ĥ ← ĥ + μ·e·x/‖x‖²`，只是换到频域用逐 bin 的除法实现"对角化近似"——它近似地把相关矩阵当对角阵处理（每个频点独立归一化），这比时域 LMS 收敛快得多，因为它隐式利用了 `R_xx` 的近似对角化结构。

**逐 bin 步长调制的意义**：频域 NLMS 天然给每个频点独立的等效步长：

```
μ_k ∝ 1 / (Σ_p |X_p[k]|² + δ)
```

于是**能量大的频点步长小、能量小的频点步长大**，使得 `H` 在所有频点以相近的相对速率收敛。这对条件数极差的语音信号是最关键的一步。

### 4.5 循环卷积问题与时域约束

这是分块频域自适应滤波**必须解决**的坑：

由于用长度 `2N` 的 FFT 表示 `N` 抽头的滤波器，若 `H_p` 的频域响应被"任意"更新，其对应的时域序列会包含**后 `N` 个非零抽头**——这意味着该 partition 实际作用于输入的 `2N` 个样本，与"每个 partition 只覆盖 `N` 个抽头"的假设矛盾，导致：

- 各 partition 的贡献在时间上**叠加/重叠错位**，等效于把错误的输入段加权；
- 系统可辨识的部分被扭曲，稳态无法收敛到真解。

**解决办法：时域约束（Time-Domain Constraint）**

每（若干）块取一个 partition `H_p`：

1. IFFT 得到时域序列；
2. 把后 `N` 点的抽头**强制置零**（并做幅度归一化）；
3. 再 FFT 回频域写回。

这保证了每个 partition 严格只覆盖 `N` 个抽头。若每块对所有 `P` 个 partition 都做一次约束，代价是 `P` 次 IFFT + `P` 次 FFT，**抵消了频域带来的全部收益**。

**因此采用"循环轮转约束"**：每块只约束一个 partition，`P` 块完成一轮。虽然"当前块的其他 `P−1` 个 partition 处于未约束状态"，但因为：

- 约束是**收缩投影**（把多余的抽头清零），单次约束不会破坏已收敛的部分；
- 未约束的误差随轮转不断被清扫；
- 每个 partition 的更新是独立的。

所以用 `O(1)` 的摊销代价达到了近似全局约束的效果。

### 4.6 滤波器长度自适应

初始阶段滤波器必须短，否则收敛太慢；稳态又需要长滤波器覆盖完整混响尾。因此长度是**时变**的：

- **初始短、稳态长**：先在小尺寸下快速收敛出主峰位置，再逐步扩展到完整尾长。
- **扩展时的平滑**：长度切换若突变会引起输出不连续与瞬时误差尖峰，因此需要在数百毫秒内**渐变**（例如线性插值有效分区数），新增的分区系数从 0 开始累积。
- **缩减/重置**：检测到回声路径剧变（延迟变化、器件切换）时，直接把超出初始长度的分区清零并退回短滤波器重新收敛。

### 4.7 频域滤波器转时域冲激响应

需要时域冲激响应时（用于分析、ERL 估计、失配修正）：

```
对每个 partition 的 H_p 做 IFFT，取前 N 点并为多通道取"绝对值最大"，拼接得到 ĥ
```

## 5. 时延估计原理

### 5.1 为什么必须先做时延估计

回顾 `y[n] = Σ h[k]·x[n−k−d] + v[n]`。如果直接让自适应滤波器从 `x[n]` 起建模：

- 滤波器需要覆盖 `[0, d + L]` 范围。若 `d` 有 500 ms 而尾长只有 50 ms，则 **90% 的 tap 被浪费在拟合纯延迟上**（且这段 `h` 全为 0，只能靠系数缓慢爬升或恰好为 0）；
- 更要命的是，**梯度下降对纯延迟的识别极慢**：`h` 前 `d` 个抽头必须全为 0，而每个抽头都要从 0 开始经历漫长的 NLMS 迭代才能形成"0 之后突然是主峰"的结构（这时相关矩阵的条件数极差）；
- 收敛时间正比于滤波器长度，`d` 大则实际不可用。

**结论**：先独立估计 `d`，把 `x` "回溯" `d` 个块来读，使得到的参考信号与 `y` 已经对齐，线性滤波器就只需覆盖 `[0, L]`——即真正的尾长。

### 5.2 基本工具：互相关与匹配滤波

`x` 与 `y` 的**互相关**：

```
r_xy[m] = E{ x[n] · y[n+m] } = E{ x[n] · Σ_k h[k]·x[n+m−k−d] } + E{x[n]·v[n+m]}
        = Σ_k h[k] · r_xx[m − k − d] + 0
```

当 `x` 是近似白信号时 `r_xx[m] ≈ σ_x²·δ[m]`，于是：

```
r_xy[m] ≈ σ_x² · h[m − d]
```

**互相关的峰值位置就直接给出了 `d`**（确切地说，给出的是 `h` 的峰值位置 `d + argmax h`）。这就是"匹配滤波"（matched filter）——把 `x` 作为模板去和 `y` 做相关，得到的就是冲激响应的估计，峰值即延迟。

### 5.3 为什么不能简单地直接互相关

实际信号不满足白噪声假设，直接互相关有几个严重问题：

1. **语音/音乐是强有色信号**，`r_xx[m]` 是宽峰，与 `h` 卷积后峰值被"抹宽"，延迟估计分辨率极差。
2. **近端语音 `v` 是强干扰**，当近端说话时互相关被完全污染（此时 `E{x·v} ≠ 0` 因两者非严格不相关或有限样本泄漏）。
3. **需要搜索的延迟范围很大**（数百毫秒），直接做长时互相关计算量巨大。
4. **环境噪声与非线性失真**会把峰值淹没。

对应的四类对策：

### 5.4 对策一：广义互相关与相位变换（GCC-PHAT）

在频域对互功率谱加权：

```
R_xy[k] = X*[k] · Y[k]
r_xy[m] = IFFT( Ψ[k] · R_xy[k] )
```

**相位变换（PHAT）加权**：`Ψ[k] = 1/|R_xy[k]|`

即只保留相位信息、丢弃幅度。因为 `h` 的幅度响应被除掉了，得到的互相关在真实延迟处呈现**极尖锐的 δ 状尖峰**，分辨率远高于普通互相关，且对 `h` 的频率着色不敏感。

代价：弱频点被过度放大 → 噪声敏感。因此实际用带正则的形式 `Ψ[k] = 1/(|R_xy[k]| + ε)`，并常加 `|R_xy[k]|` 的幂次加权（`β = 0~1` 之间调节锐度与鲁棒性）。

### 5.5 对策二：自适应匹配滤波器组

比"每次重算互相关"更稳健、更省算力的做法是**用一个自适应 FIR 滤波器在线跟踪 `h`**：

设一个长度 `M` 的 FIR `w`，用 NLMS 自适应：

```
s[n] = Σ_k w[k] · x_ref[n−k]
e[n] = y[n] − s[n]
w ← w + μ · e[n] · x_ref[n] / ‖x_ref‖²
```

这里 `x_ref` 是参考信号的某一段（带偏移）。当 `w` 收敛后，**`w` 的能量峰值位置就是延迟**：

```
lag = argmax_k |w[k]|²
```

为什么这比 GCC-PHAT 好：

- **带记忆的递归估计**，不需要长的 FFT 批处理，可逐样本/逐块更新；
- 有自适应门限（能量归一化）天然抑制弱激励段；
- 可以直接控制**搜索范围**（滤波器长度）和**分辨率**。

### 5.6 对策三：滤波器组覆盖大范围延迟

单个短滤波器（比如 512 抽头 @ 降采样域 ≈ 128 ms）覆盖不了 500 ms 的范围。两个思路：

**(a) 一个超长滤波器**
- 缺点：NLMS 收敛慢、对单个强峰不敏感、算力大。

**(b) 多个短滤波器组成"滤波器组"，彼此错开一个固定步进** ⭐

```
f_0:  |===== M 抽头 =====|
f_1:         |===== M =====|          步进 Δ < M
f_2:                 |===== M =====|
...
f_{P−1}:                          |===== M =====|

总覆盖 = (P−1)·Δ + M
```

每个滤波器**独立做 NLMS**，都用自己的输入偏移。

**每块的处理**：

1. 对每个滤波器，用当前块算其输出与残差能量 `E_i = Σ e_i[n]²`；
2. 每个滤波器从自身 `w` 里取峰值位置 `lag_i`，并做**可靠性判据**：
   - 峰值不能落在滤波器边界（边缘的峰是截断造成的假峰）；
   - 残差必须显著小于"完全不滤波"的基线能量（如 `E_i < θ · Σ y[n]²`，`θ ≈ 0.2`），即该候选必须能解释掉大部分麦克风能量；
3. 在所有可靠候选中，**取残差能量最小的那个**作为本块的延迟候选。

**为什么用多个短滤波器而不是一个长滤波器**：

- 每个短滤波器只需在自己那一段延迟上收敛，**等价于把条件数极差的全局问题分解成若干个良态子问题**；
- 收敛速度取决于各滤波器自身长度 `M`，而不是总覆盖范围；
- 只有真正包含回声主峰的那个（或少数几个）滤波器能通过残差判据，其余的因"峰不在覆盖内"而失败——**天然的并行假设检验**；
- 某段回声路径变化时，只有对应的滤波器需要重新收敛。

**处理重叠区**：当两个滤波器在重叠区都命中同一延迟时，应**优先选择下标更小（延迟更早）的那个**，为后续的"前回声"检测留出余量。

**分辨率**：`w` 的峰值定位精度受限于抽头间隔。要获得亚块精度需要插值或提高采样率。实际做法是先**降采样**（见 5.7），在降采样域做粗定位，误差在若干毫秒内即可满足 AEC 需求。

### 5.7 对策四：降采样以降低算力

时延估计的精度需求是"块级"（几毫秒），远低于音频带宽需求。因此：

1. 参考信号与麦克风信号都做**抗混叠低通后降采样**（如 4× 或 8×）；
2. 在降采样域做匹配滤波。

收益：

- 峰值搜索与 NLMS 的抽头数按倍数减少，算力降 4～8 倍；
- 同等抽头数下"总覆盖时间"放大 4～8 倍；
- **牺牲的只是延迟分辨率**（从 1 样本变为 4 或 8 样本，即 0.25 ms → 1~2 ms），对 AEC 完全够用。

**降采样前的滤波设计原则**：

- **抗混叠低通**：截止频率必须低于降采样后奈奎斯特频率，否则高频折返会在互相关上产生伪峰；
- **高通（或带通）**：回声路径在极低频往往信噪比差、且近端噪声集中在低频，把 1 kHz 以下滤掉能显著提高互相关的可信度。极端情况下用**带通**（只保留 1~2 kHz）效果更好，因为该频段既有足够语音能量，又少有环境噪声；
- 降采样后可用**简单抽取**（取每第 N 个样本）而非多相滤波，因为前面已做了抗混叠。

### 5.8 多帧聚合：直方图投票

单块得到的延迟候选会抖动（远处说话、窄带音乐、瞬时噪声都会造成假峰）。**不能直接用**。需要用多帧共识来稳定。

**滑动直方图（Sliding Histogram Voting）**：

- 维护一个长度为"最大可能延迟"的直方图 `cnt[d]`，以及一个长度为 `W` 的 FIFO 记录最近 `W` 个候选；
- 每来一个新候选：
  - `cnt[FIFO_oldest] -= 1`（移除最老的）
  - `cnt[new_candidate] += 1`（加入最新的）
  - FIFO 轮转
- **当前候选** = `argmax_d cnt[d]`（直方图众数）

这是 `O(1)` 的滑动窗口众数，本质是**对延迟候选做非参数密度估计**——延时估计问题从此变成"找众数"的鲁棒问题。

**双门限输出机制**（关键设计）：

设两个计数门限 `T_coarse < T_refined`：

| 条件 | 输出 | 语义 |
|---|---|---|
| `cnt > T_coarse` 且尚未出现过 refined | `kCoarse` 级估计 | 冷启动阶段，允许"大胆猜测"，尽快让 AEC 跑起来 |
| `cnt > T_refined` | `kRefined` 级估计 | 已充分确认 |
| 出现过 refined 之后 `cnt` 只回到 coarse 区间 | **不输出 coarse** | 一旦可靠过，就不退回猜测，避免引入错误延迟 |

这个机制的意义是：**AEC 启动时的收益远大于风险**（一开始 AEC 是关闭的，猜错的代价只是重来），而运行中猜错代价很大（会切掉真实说话），因此策略不同。

### 5.9 保护余量（Headroom）

不要把报告的延迟设成"恰好是峰值位置"，而要**预留一小段余量**（如 2~5 ms），让真实回声落在滤波器覆盖范围的**内部偏后位置**。

原因：

- 估计有量化误差（降采样精度、峰位精度）；
- 前回声（pre-echo）必须能落在滤波器内；
- 若估计偏大（把延迟报得比实际大），回声主峰落在滤波器**前面**——这部分是**不可表示**的（滤波器因果，无法表示负延迟），只能靠抑制器收拾；
- 因此宁可"少补偿一点"，让多余的回声落在滤波器能覆盖的区间内。

### 5.10 前回声（Pre-Echo）对齐

**定义**：在回声主峰**之前**还存在可感知的早期反射/泄漏能量。

若只把延迟对齐到最强峰，则主峰前的能量落在滤波器第 0 个 tap 之前，无法被消除，残留明显（尤其在强反射的房间里）。

**检测原理**：在匹配滤波过程中，除了记录完整卷积的残差，还记录**部分卷积和的误差**——即"只用到 `w` 的前 `k` 个抽头时"的预测误差能量：

```
e_partial[k] = (Σ_{j<k} w[j]·x[...j]) − y     （逐段累加）
acc[k] = 平滑(|e_partial[k]|² / 全长残差能量)
```

`acc[k]` 表征"滤波器前 `k` 个抽头能把多少 `y` 解释掉"。

**前回声起点** = 从峰值位置向**更小延迟方向**扫描，第一个使 `acc[k]` 超过阈值（如 0.5，即已能解释一半能量）的位置。这个位置就是"回声实质开始"的时刻，应当作为对齐点而非主峰位置。

**平滑细节**：`acc[k]` 的更新要**快降慢升**——误差变小立即跟随（真实的回声起始点会立刻反映），误差变大只按很小的系数缓升（避免瞬时噪声把起始点误判到很早的位置）。

**只对上次命中的那个滤波器做前回声计算**（因为其余滤波器不可能成为对齐目标），可省算力。

### 5.11 从"样本延迟"到"缓冲深度"

估计出的 `d`（单位：样本）最终要变成 **`d_blocks = d >> log2(block_size)`**，用来偏移参考信号的读取指针。

**迟滞（Hysteresis）**：延迟估计会持续小幅抖动，若每次都跟随会造成参考信号频繁跳变、滤波器反复重置。因此：

- **延迟变大时，小幅变化不跟随**（如仅增大 1 块就先忍着）。原因是对应"要读更早的参考数据"可能已被覆盖，且延迟增大的方向更可能是**误判**（比如某个弱峰偶然胜出）。
- **延迟变小时立即跟随**（减小延迟永远安全，数据一定还在）。
- 迟滞**只在高置信度（refined）下启用**：低置信度阶段本来就该快速响应。

### 5.12 稳定性重置与时钟漂移

**(a) 稳定后主动重置**

若延迟连续若干秒保持不变，说明已锁定，历史累积的匹配滤波器 `w` 与直方图都是"过期信息"。此时把它们清零重新累积，可以让**后续的跟踪更灵敏**（清空后少量新样本就能改变众数，而不必与几十秒的旧计数抗衡）。这个重置**不重置置信度标志**，因此不会退回 coarse 猜测。

**(b) 时钟漂移检测**

两端设备使用各自晶振，标称同频但存在 ppm 级偏差。表现为延迟估计以 **±1 样本的规律缓慢单调漂移**：

```
... d−3, d−2, d−1, d    →  正向漂移（远端时钟偏慢）
... d+3, d+2, d+1, d    →  负向漂移
```

**检测原理**：记录最近若干次延迟估计，识别"单调递增/递减且步长为 ±1/±2/±3"的模式：

- 观察到"呈规律漂移趋势" → 标记为**疑似**（probable）
- 连续的模式确认 → 标记为**确认**（verified）
- 连续数十秒延迟稳定 → 回到无漂移状态

漂移一旦确认，需要通知下游模块（抑制器）切换到**适应漂移的保守策略**，因为此时参考信号与回声在缓慢错位，线性滤波器永远无法完全收敛。

### 5.13 时延补偿接口

对齐的实现方式：维护一个参考信号的环形缓冲，包含**块缓冲**和**频域/频谱缓冲**（后者是前者各块的 FFT）。

- 把"当前应读位置"按估计延迟 `d_blocks` 偏移：`read = write ⊕ d_blocks`；
- 于是后续所有模块只要访问"当前位置"，拿到的就是**已与麦克风对齐**的参考数据；
- **关键收益**：线性滤波器不需要任何附加的延迟参数，直接从当前对齐位置开始做分块卷积即可。

**延迟变化时的处理**：延迟一变，原先收敛的滤波器系数完全错位，必须视为"回声路径剧变"：

- 清空所有滤波器系数（两级都清）；
- 滤波器长度退回初始（短）状态，重新渐变到稳态；
- 自适应步长配置退回"初始/激进"参数；
- 抑制器回到保守初始状态。

### 5.14 时延估计流程总览

```
参考块 x ──► 通道选择/混音 ──► 抗混叠低通+高通 ──► 降采样 ──┐
                                                            ├─► 匹配滤波器组 (P 个短 NLMS)
麦克风块 y ─► 通道选择/混音 ──► 抗混叠低通+高通 ──► 降采样 ──┘        │
                                                                     ├─ 每个滤波器：残差 E_i、峰位 lag_i
                                                                     ├─ 可靠性：峰不在边界 && E_i < θ·基线
                                                                     └─ 选残差最小者 → 本块候选 lag
                                                                              │
                                                            ┌─────────────────┘
                                                            ▼

                                                      ├─ 输出 {coarse|refined, delay}
```

## 6. 双讲、发散与鲁棒性机制

### 6.1 双讲（Double-Talk）问题

当近端也在说话时，`e[n]` 中不仅有回声残差，还有很强的 `v[n]`。NLMS 无法区分"误差来自 `h` 不对"还是"来自 `v`"，于是会把 `v` 也当成要消除的成分而去修改 `ĥ`，导致：

- `ĥ` 被推向错误方向（把近端语音的"路径"也学进去）；
- 严重时发散，AEC 输出削掉近端语音。

### 6.2 对策一：双讲检测（DTD）+ 冻结

检测"近端是否在说话"（常用依据：`e` 与 `y` 的能量比异常升高、`y` 的能量比 `x` 高很多、`e` 与 `x` 的相关性下降），一旦判定为双讲就：

- 步长置 0（完全冻结）是最简单粗暴的做法；
- 更平滑的做法是**按双讲程度连续缩放步长**。

缺点是 DTD 一旦误判（把弱回声当双讲 → 停止更新；把双讲当回声 → 学坏）都会有害，因此需要滞后与多特征融合。

### 6.3 对策二：步长自适应中含"远端/近端"项

比 DTD 更优雅的做法：**让步长公式自带双讲抑制能力**。

注意到误差能量 `E` 的功率谱中包含两端：

```
E ≈ H_err · X   （滤波器模型误差 × 参考）   +   V   （近端 + 噪声）
```

于是最小化"每 bin 的均方误差"的**最优步长**可推出为：

```
μ[k] ∝ H_err[k] / ( H_err[k]·X²[k] + α·E²[k] )
```

其中 `H_err[k]` 是**滤波器模型误差的估计**（"我离真解还有多远"）。这个式子的行为非常漂亮：

- **激励强（X² 大）** → 分母大 → 步长小。合理：此时梯度估计虽然准，但适应太快会导致失调大。
- **误差谱 E² 大（近端说话 / 有残余回声）** → 分母大 → 步长小。**这就在没有显式 DTD 的情况下自然实现了双讲保护**。
- **模型误差 H_err 大（还没收敛）** → 步长大。合理：前期要快。
- 分子分母同含 `H_err`，因此当 `H_err` 收敛到很小的时候步长并不趋于 0（比值保持有意义的量级）。

### 6.4 模型误差估计 `H_err` 的递推

`H_err[k]` 无法直接观测，用递推估计：

```
H_err[k] ← H_err[k] − λ · μ[k] · X²[k] · H_err[k]      （激励越多，模型误差估计越小）
```

即"每次成功更新都减少对模型误差的估计"，减少量正比于步长与激励能量。

再叠加**泄漏/注入项**，用滤波器自身能量 `ERL[k] = Σ_p |H_p[k]|²` 为正则：

```
H_err[k] += γ · ERL[k]
```

`γ` 取小值（收敛后）或大值（判定为发散时）。最后做**上下限钳位** `[floor, ceil]`。

这个机制的作用：

- **防止步长"冻结"**：若无注入项，`H_err → 0` 会让步长消失，滤波器再也无法跟踪变化；
- **正则化/抗漂移**：注入项把系数向"与当前滤波器能量成比例"的方向拉，本质上是**频域泄漏**的一种形式；
- **发散自救**：当"精滤波器"的误差能量超过"粗滤波器"时（说明精滤波器发散），使用大的 `γ` 快速增大 `H_err`、重新加速收敛。

### 6.5 对策三：激励门限（Noise Gate）

逐 bin 检查参考信号功率：

```
若 X²[k] < gate  →  μ[k] = 0（本 bin 本块不更新）
```

意义：

- 远端静音时**完全停止更新**，避免自适应滤波器被纯噪声/近端语音"训练"；
- 门限通常按"白噪声功率等效"设定（如 −39 dBFS 的 WGN 功率）；
- 弱激励频段不更新，配合泄漏项将那些 bin 的系数压回 0。

### 6.6 对策四：窄带/单频区域的屏蔽

若参考信号在某些 bin 上是**强窄带**（音乐中的单音、测试信号），则：

- 这些 bin 的自相关矩阵近乎奇异（激励向量几乎完全相关）；
- `μ = 1/X²` 在这些 bin 上虽然有界，但更新方向完全被该单音主导，会把 `h` 拉向只拟合该频率的错误解（"把滤波器变成窄带滤波器"）。

**对策：围绕检测到的窄带峰，把邻域的 `μ[k]` 置零**，即该频段不更新。同时用一个"频域掩蔽"把窄带区域的更新彻底关闭，直到参考信号恢复宽带。

### 6.7 对策五：失配修正（Misadjustment Scaling）

若由于某种原因滤波器"过冲"（系数整体幅度偏大）——比如路径衰减突变、或前一段双讲导致失调——表现为**预测误差能量持续远大于麦克风信号能量**（`Σ e² / Σ y²` 长期偏高）。

**对策**：累积若干块的 `Σ e²` 与 `Σ y²`，若比值超过门限，则把**整个滤波器**（及冲激响应估计、及当前输出）按一个缩放因子整体缩小：

```
scale = 2 / sqrt(inv_misadjustment)      （inv_misadjustment 为累积的 e²/y² 比值）
ĥ ← scale · ĥ
e  ← y − scale · (ĥ ⊛ x)                （输出同步修正，避免不连续）
```

特点：

- **不做清零重置**（保留已收敛的结构），只做整体缩放——比"清空重来"温和得多，恢复快；
- 有意只修正"估计失配量的一半"（`scale` 里含 2 的因子），避免过矫正振荡；
- 修正后重置累积计数器。

### 6.8 对策六：粗/精两级滤波器互补

见 [第 7 节](#7-滤波器架构设计原理)。

## 7. 滤波器架构设计原理

### 7.1 为什么用"粗 + 精"两个滤波器

单一滤波器无法同时满足两个矛盾的需求：

| 需求 | 要求 |
|---|---|
| 快速获得可接受的初始回声消除 | **大步长、短滤波器** |
| 稳态高 ERLE、抗双讲 | **小步长、长滤波器、强双讲保护** |

于是用两个并行滤波器：

**粗滤波器（Coarse）**
- 步长固定且大（如 0.7~0.95）；
- 收敛快、鲁棒，但稳态精度有限（失调大）；
- 作用是：**快速给精滤波器提供一个"大方向正确"的起点**，以及在精滤波器暂时失效时兜底输出。

**精滤波器（Refined）**
- 步长自适应（含 `H_err` 递推、双讲抑制、泄漏、能量等）；
- 稳态精度高；
- 输出作为最终结果。

### 7.2 粗滤波器跟随精滤波器（"跳变升级"）

关键机制：**当粗滤波器长期表现不如精滤波器时，直接把精滤波器的系数整体复制给粗滤波器**。

判据：连续若干块（如 5 块）精滤波器的残差能量都小于粗滤波器（`e²_refined < e²_coarse`）。

- 复制时把粗滤波器的长度设成与精滤波器一致（可能是扩展）；
- 复制后设置一个 **hangover 期间**（若干块），在此期间精滤波器的自适应使用"非发散"的泄漏参数（不让粗滤波器的暂时性差表现影响精滤波器的收敛速度）；
- 复制前，粗滤波器用自己的残差和精滤波器的误差谱继续更新（注意更新用的是精滤波器的 `E`，因为此时精滤波器的解才是目标）。

这个机制等价于**用精滤波器的结果周期性重新播种粗滤波器**，避免粗滤波器长期停留在过时的解上。

### 7.3 输出选择：什么时候用粗滤波器的输出

某些情况下精滤波器的输出反而不如粗滤波器：

- 精滤波器暂时发散（`e²_refined` 异常大）；
- 双讲导致精滤波器被带偏，而粗滤波器步长大、恢复快；
- 强回声场景下精滤波器还在适应中。

**选择判据（示例逻辑）**：

```
若  粗滤波器残差 < 0.9 × 精滤波器残差
且  麦克风能量足够大（不是静音段）
且  某一级的"回声估计能量"足够大（确实有回声在消）
则  改用粗滤波器输出

若  粗滤波器残差 < 精滤波器残差
且  麦克风能量 < 精滤波器残差（说明精滤波器在放大误差）
则  改用粗滤波器输出（精滤波器发散了）

否则用精滤波器输出
```

这三条判据对应三种不同的场景：**粗更好**、**精发散**、**默认信任精**。

### 7.4 切换时的平滑（Cross-Fade）

两级输出之间切换会造成波形跳变（听感上"咔哒"）。**对策：交叉淡化**。

保存"上一次使用的输出"，切换时在前若干样本（如 20~60 样本，即 1~4 ms）内做线性插值过渡：

```
out[i] = from[i]·(1 − i/K) + to[i]·(i/K),     i = 0…K−1
out[i] = to[i],                                i ≥ K
```

`K` 取一个块内的一小部分（远小于块长，因此每块最多一次过渡且不跨块）。

## 8. 性能度量

### 8.1 ERL（Echo Return Loss）

回声路径本身的衰减，与 AEC 无关：

```
ERL = 10·log10( E{x²} / E{e_echo²} )   [dB]
```

常用于判断"这个房间的回声有多强"。在线估计可用互相关峰值或滤波器频率响应之和：

```
ERL_est[k] = Σ_p |H_p[k]|²          （滤波器在频点 k 的总增益）
```

### 8.2 ERLE（Echo Return Loss Enhancement）

AEC 带来的额外衰减：

```
ERLE = 10·log10( E{y²} / E{e²} )   [dB]
```

这是**衡量 AEC 性能的核心指标**。

关键注意：ERLE 的计算必须**只在远端单讲段**（无近端语音）进行，否则 `v` 会污染分母/分子，得到无意义的结果。因此 ERLE 的测量与"透明模式/近端检测"耦合在一起。

### 8.3 双讲时的指标失效

双讲时 `e` 中主要是 `v`，ERLE 会显得很低，但这**不是** AEC 变差了。因此不能用双讲段的 ERLE 来评估性能。

## 9. 线性 AEC 的固有局限

### 9.1 冲激响应长度有限

混响尾随时间衰减，但影响可感知到 `T60` 之后。滤波器长度有限 ⟹ **尾部的晚期混响无法消除**，表现为残余回声。这部分只能靠抑制器（谱减/维纳增益）处理。

### 9.2 非线性失真

扬声器在大音量下产生**谐波失真、互调失真**；功放削波；麦克风过载。非线性回声无法被线性滤波器表示。典型表现：

- 音量越大残留越多（甚至 AEC 完全失效）；
- 自适应滤波器"追不上"，因为目标本身随幅度变化。

**对策**：前置"回声路径增益控制"（限制扬声器信号峰值）、非线性建模、以及后置抑制器。

### 9.3 时变与时钟漂移

- 采样时钟漂移使参考与回声持续缓慢错位，线性滤波器永远处于"追"的状态；
- 移动设备、用户走动造成路径瞬变。

### 9.4 双讲的本质困难

只要近端信号与参考信号在有限样本上相关（统计上必然如此），"消除回声"与"保留近端"就存在**不可完全分清的模糊性**。所有双讲保护机制都是在"消回声能力"和"保护近端"之间做权衡。

### 9.5 因此必须有非线性的后处理

线性 AEC 在理想单讲条件下可以达到很高的 ERLE（如 30~50 dB），但：

- 双讲段它主动"放水"（步长减小甚至冻结）→ 残余回声变多；
- 非线性失真、晚期混响、漂移都留下残余。

因此工程上 AEC 从来不是"线性滤波器"单独工作，而是：

```
线性 AEC（提供高 ERLE，但不保证充分）
      ↓ 输出 e[n] 及各种统计量（E², S²_linear, Y², ERL, 收敛状态…）
残余回声估计（估计"还剩多少回声"，区分近端与残余）
      ↓
抑制器（时变/频变增益，谱减风格的软判决，把残余回声压到听不见）
      ↓
舒适噪声（填补被压制频段的空隙，避免"抽真空"的听感）
```

**线性部分的价值在于"把回声降到抑制器能处理的量级"**——若线性部分完全失效，抑制器为了压住回声不得不把所有信号都压掉（包括近端语音），通话不可用。这是"线性 + 非线性"分工的根本原因。
